FAREVER TRANSLATE
=================

Proyecto comunitario gratuito y no afiliado a Shiro Games.
Uso personal y bajo responsabilidad del usuario.

IMPORTANTE
----------

- No extraigas los archivos directamente sobre la carpeta de Farever.
- Farever debe estar cerrado al instalar, actualizar o desinstalar.
- Necesitás .NET 8 Desktop Runtime x64:
  https://dotnet.microsoft.com/en-us/download/dotnet/8.0/runtime
- El minimapa no es obligatorio. Si ya tenés una versión compatible, el
  instalador conservará ambos.
- Si existe otro dinput8.dll desconocido, la instalación se cancela sin
  modificarlo.

INSTALAR O ACTUALIZAR
---------------------

1. Extraé todo este ZIP en una carpeta aparte.
2. Hacé doble clic en Instalar.cmd.
3. Si Farever no se detecta, seleccioná la carpeta que contiene Farever.exe.

USAR
----

- F6 muestra u oculta el panel.
- Alt sola habilita los controles del panel.
- Alt nuevamente devuelve el mouse al juego.
- Configurá tu propia API key de Google Cloud Translation desde "Clave".
- Solo se envía a Google la línea que decidís traducir.

DESINSTALAR
-----------

Conservá esta carpeta extraída. Cerrá Farever y ejecutá Desinstalar.cmd.
Si usabas el minimapa, se restaurará byte por byte.
